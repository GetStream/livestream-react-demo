## Livestream Demo

This repository holds the codebase for our Livestream Demo, available here:
- https://getstream.io/video/livestreaming/
- https://livestream-react-demo.vercel.app/

## Running the demo locally
- clone this repository
- in the repo root run `pnpm install`
- `cd ui && pnpm build`
- `cd ../app`
- `pnpm dev`
